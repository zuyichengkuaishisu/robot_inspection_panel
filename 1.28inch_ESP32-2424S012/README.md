# ESP32-2424S012 hardware references

This directory keeps only the board-specific material needed to develop and diagnose the inspection panel:

- `1-Demo/Demo_Arduino/2_1_Helloworld/`: minimal display example
- `2-Specification/`: board specification
- `3-Structure_Diagram/`: mechanical drawings
- `4-Driver_IC_Data_Sheet/`: ESP32-C3 module datasheet
- `5-Schematic/`: board and module schematics
- `6-User_Manual/`: vendor user manual

Copies of third-party Arduino libraries, generated demo assets, Windows flashing tools and vendor burn images are excluded. The project dependencies should be installed through the Arduino library manager or the normal local Arduino library workflow.
